# Integración de Wavebox

La capa `network` monta recintos arbitrarios con los elementos acústicos
del motor. PH1, BP8S, BPB y DBR usan la misma red. Los resultados incluyen
presiones y caudales complejos, impedancia diferencial, excursión y potencia.
